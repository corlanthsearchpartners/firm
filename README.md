# Corlanth Search Partners — Website

A premium, conversion-focused marketing website for an executive search firm. Built with vanilla HTML, CSS, and JavaScript for maximum performance and zero build-step complexity.

## 🎯 Project Goals

- Convert visiting companies into retained/contingent search clients
- Convert visiting executives into the talent pipeline
- Rank organically for niche "[sector] executive search" keywords
- Load fast (Lighthouse 90+ mobile) while looking premium and trustworthy

## 🏗️ Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Modular architecture with CSS variables
- **Vanilla JavaScript** — No framework overhead
- **Three.js** (via CDN) — Signature 3D hero element (lazy-loaded)
- **External images** — All imagery loaded from `https://freelankarx.com/logo.png` (placeholder; swap URLs later)
